# FEMC Engineering Dependency Governance

**Version:** 1.0.0
**Status:** Engineering Foundation

## Dependency Review

Material dependencies should be evaluated for:

- purpose;
- maturity;
- security;
- licensing;
- maintenance;
- performance;
- portability;
- vendor lock-in;
- replacement difficulty.

## Rules

A dependency should not become part of FEMC merely because it is convenient.

Critical dependencies require an explicit replacement or continuity consideration.

## AI Dependencies

AI providers and model SDKs remain replaceable implementation dependencies.

## Principle

Every dependency creates future responsibility. Add dependencies deliberately.

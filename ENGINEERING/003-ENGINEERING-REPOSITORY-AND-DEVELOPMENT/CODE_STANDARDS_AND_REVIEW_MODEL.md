# FEMC Code Standards and Review Model

**Version:** 1.0.0
**Status:** Engineering Governance
**Owner:** Engineering Office

## Review Focus

Code review should assess:

- correctness;
- domain-boundary adherence;
- security/privacy implications;
- test coverage;
- failure handling;
- maintainability;
- unnecessary complexity;
- observability;
- migration implications.

## Rules

Review should focus on risk and behavior, not stylistic preference alone.

Material deviations from established engineering or architectural rules require explicit rationale.

## Principle

Code review is a second set of engineering eyes, not a ceremonial approval step.

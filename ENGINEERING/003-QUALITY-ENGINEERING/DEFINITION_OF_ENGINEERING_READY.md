# FEMC Definition of Engineering Ready

A capability is engineering-ready for release consideration when:

- [ ] requirements are understood;
- [ ] architecture alignment is confirmed;
- [ ] canonical data ownership is clear;
- [ ] authorization behavior is tested;
- [ ] privacy implications are addressed;
- [ ] failure behavior is understood;
- [ ] observability exists;
- [ ] automated tests cover material behavior;
- [ ] migration implications are addressed;
- [ ] performance is appropriate;
- [ ] accessibility is addressed;
- [ ] security review is complete where required;
- [ ] rollback or mitigation is understood;
- [ ] documentation is sufficient;
- [ ] unresolved risks have owners.

## Principle

“Works on my machine” is not an FEMC engineering readiness criterion.

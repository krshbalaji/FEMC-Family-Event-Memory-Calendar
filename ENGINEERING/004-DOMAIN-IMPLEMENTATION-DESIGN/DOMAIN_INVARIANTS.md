# FEMC Domain Invariants

**Version:** 1.0.0
**Status:** Engineering Design
**Owner:** Engineering Office

## Core Invariants

### Identity
A person and an account are distinct concepts.

### Relationship
A relationship is not equivalent to authorization.

### Event
An event has temporal meaning and may involve multiple people.

### Memory
A memory may originate from an event but does not require one.

### Media
Media is an asset that may contribute to one or more memories.

### Family Context
Sensitive family information must remain associated with an authorized family context.

### AI
AI output is not canonical merely because it is generated by the system.

## Implementation Rule

Invariants must be enforced at appropriate domain boundaries and covered by tests.

## Principle

If an invariant matters to family trust, it must not exist only as developer convention.

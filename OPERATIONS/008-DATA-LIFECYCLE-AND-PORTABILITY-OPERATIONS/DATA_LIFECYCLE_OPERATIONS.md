# FEMC Data Lifecycle Operations

**Version:** 1.0.0
**Status:** Operations
**Owner:** Operations Office

## Lifecycle

```text
CREATE → USE → CHANGE → ARCHIVE → EXPORT/PRESERVE → DELETE
```

## Operational Responsibilities

Operations must ensure lifecycle jobs are:

- observable;
- authorized;
- repeatable;
- recoverable;
- auditable where appropriate.

Derived copies, indexes, caches, media derivatives, and AI artifacts must be considered when lifecycle actions affect canonical information.

## Principle

A data lifecycle operation is complete only when all FEMC-managed representations behave consistently with the intended policy.

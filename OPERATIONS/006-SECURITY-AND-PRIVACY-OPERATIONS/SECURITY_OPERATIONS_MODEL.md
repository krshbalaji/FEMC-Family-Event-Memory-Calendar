# FEMC Security Operations Model

**Version:** 1.0.0
**Status:** Operations
**Owner:** Operations Office

## Security Operating Cycle

```text
PREVENT
 ↓
DETECT
 ↓
ASSESS
 ↓
CONTAIN
 ↓
ERADICATE / RECOVER
 ↓
LEARN
```

## Focus Areas

- suspicious access;
- privilege misuse;
- credential compromise;
- dependency vulnerabilities;
- unusual data movement;
- authorization failures;
- AI-related data exposure.

## Principle

Security operations protect family trust continuously; they are not limited to incident response.

# FEMC Production Operating Model

**Version:** 1.0.0
**Status:** Operations Foundation

## Operating Cycle

```text
OBSERVE
 ↓
ASSESS
 ↓
ACT
 ↓
VERIFY
 ↓
DOCUMENT
 ↓
IMPROVE
```

## Required Operational Views

Operations should be able to understand:

- availability;
- performance;
- error health;
- dependency health;
- data integrity signals;
- security signals;
- capacity;
- active incidents;
- recent releases;
- recovery readiness.

## Principle

Production operation should be evidence-driven rather than intuition-driven.

# FEMC Data Principles

**Version:** 1.0.0
**Status:** Data Foundation
**Owner:** Data Office

## Principles

1. Canonical meaning has explicit ownership.
2. Data definitions are discoverable.
3. Provenance is preserved.
4. Data quality is measurable.
5. Derived data is distinguishable from source truth.
6. Minimum necessary data is used.
7. Authorization follows the data.
8. Lifecycle is explicit.
9. Migration preserves meaning.
10. Deletion and preservation are deliberate.
11. Data remains portable where practical.
12. Family data integrity outranks technical convenience.

## Principle

A technically valid record can still be wrong for FEMC if it no longer represents the family meaning correctly.

# FEMC Data Definition and Semantic Standards

**Version:** 1.0.0
**Status:** Data Governance
**Owner:** Data Office

## Standards

Material data concepts should define:

- name;
- meaning;
- ownership;
- allowed states;
- relationships;
- temporal behavior;
- provenance;
- sensitivity;
- lifecycle.

## Rule

The same concept should not acquire conflicting meanings in different modules merely because each module has its own implementation.

## Principle

Shared vocabulary reduces semantic drift across Product, Architecture, Engineering, AI, Search, and Operations.

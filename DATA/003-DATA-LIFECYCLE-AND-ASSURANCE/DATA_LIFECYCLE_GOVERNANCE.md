# FEMC Data Lifecycle Governance

**Version:** 1.0.0
**Status:** Data Assurance
**Owner:** Data Office

## Lifecycle

```text
COLLECT / CREATE
 ↓
VALIDATE
 ↓
STORE
 ↓
USE
 ↓
DERIVE / SHARE
 ↓
ARCHIVE / RETAIN
 ↓
DELETE / PRESERVE
```

## Requirements

Every material data class should have an understood lifecycle, including:

- canonical records;
- media metadata;
- indexes;
- AI-derived information;
- exports;
- backups;
- operational copies.

## Principle

Data governance follows information through every representation, not just the primary database.

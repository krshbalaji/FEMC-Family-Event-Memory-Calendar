# FEMC Data Migration and Reconciliation Assurance

**Version:** 1.0.0
**Status:** Data Assurance
**Owner:** Data Office

## Migration Controls

A material migration should establish:

- source inventory;
- target definition;
- transformation rules;
- validation rules;
- reconciliation method;
- exception handling;
- rollback/recovery strategy;
- post-migration verification.

## Reconciliation

Counts alone are insufficient. Validate semantic integrity for important family records.

## Principle

A successful migration preserves what the data means, not merely how many rows moved.

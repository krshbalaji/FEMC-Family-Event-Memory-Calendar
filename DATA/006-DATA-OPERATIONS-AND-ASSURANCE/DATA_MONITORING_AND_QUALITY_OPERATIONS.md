# FEMC Data Monitoring and Quality Operations

**Version:** 1.0.0
**Status:** Data Operations
**Owner:** Data Office

## Monitor

Where appropriate, monitor:

- quality failures;
- missing data;
- duplicates;
- unexpected changes;
- schema drift;
- reconciliation failures;
- pipeline failures;
- stale derived data.

## Response

Significant anomalies should have:

- owner;
- severity;
- containment;
- investigation;
- correction;
- verification.

## Principle

Data quality is an operating condition, not a one-time migration exercise.

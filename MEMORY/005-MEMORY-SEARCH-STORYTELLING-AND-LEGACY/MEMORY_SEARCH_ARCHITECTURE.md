# FEMC Memory Search Architecture

**Version:** 1.0.0
**Status:** Memory Intelligence
**Owner:** Memory Office

## Search Dimensions

Search may combine:

- person;
- relationship;
- time;
- event;
- place;
- story;
- media;
- theme;
- natural-language meaning.

## Rules

Search results must respect memory visibility and authorization.

Search ranking should favor meaningful relevance rather than engagement optimization.

## Principle

Memory search should help families find what they mean, not merely what contains matching words.

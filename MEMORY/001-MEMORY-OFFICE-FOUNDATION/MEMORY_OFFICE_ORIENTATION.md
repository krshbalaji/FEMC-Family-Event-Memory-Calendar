# FEMC Memory Office Orientation

**Version:** 1.0.0
**Status:** Memory Foundation
**Owner:** Memory Office

## Mission

Preserve, organize, connect, and present family memory so that people can understand not only what happened, but why it matters to the family.

## Memory Owns

- memory semantics;
- stories and recollections;
- historical context;
- memory relationships;
- provenance;
- memory lifecycle;
- preservation meaning;
- memory quality and assurance.

## Memory Does Not Own

Memory does not redefine:

- identity;
- family membership;
- event truth;
- place truth;
- media integrity;
- privacy;
- security;
- communication;
- technical storage.

## Principle

A memory is more than a record of the past; it is family context carried through time.

# FEMC Memory Responsibility and Decision Boundaries

**Version:** 1.0.0
**Status:** Memory Foundation
**Owner:** Memory Office

## Memory Decisions

The Memory Office governs:

- memory representation;
- story context;
- recollection state;
- provenance;
- memory relationships;
- historical interpretation boundaries;
- preservation intent;
- memory lifecycle.

## Coordination

Memory coordinates with:

- Identity for people;
- Family for shared context;
- Events for occurrences;
- Places for geographic context;
- Media for artifacts;
- Search for discovery;
- Privacy for visibility;
- AI for assisted interpretation.

## Principle

Memory connects family meaning across time without claiming authority over facts owned by other domains.

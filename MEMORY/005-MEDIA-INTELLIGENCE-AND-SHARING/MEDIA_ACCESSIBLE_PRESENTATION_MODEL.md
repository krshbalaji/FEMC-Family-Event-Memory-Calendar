# FEMC Media Accessible Presentation Model

**Version:** 1.0.0
**Status:** Media Experience Architecture
**Owner:** Media Office

## Presentation

Media may be transformed for:

- captions;
- transcripts;
- audio descriptions;
- alternative text;
- translations;
- responsive display;
- bandwidth constraints.

## Rules

Accessible representations should retain source linkage and should not be mistaken for the original media.

## Principle

Accessibility increases the number of family members who can experience an artifact without changing what the artifact is.

# FEMC Media Sharing and External Delivery Model

**Version:** 1.0.0
**Status:** Media Governance
**Owner:** Media Office

## Sharing

Sharing may involve:

- family members;
- invited recipients;
- external services;
- exports;
- temporary links;
- presentations.

## Requirements

Every material sharing path should consider:

- authorization;
- scope;
- expiry;
- recipient;
- derivative selection;
- metadata exposure;
- revocation;
- provider retention.

## Principle

Sharing a media representation does not transfer ownership of the family's canonical media context.

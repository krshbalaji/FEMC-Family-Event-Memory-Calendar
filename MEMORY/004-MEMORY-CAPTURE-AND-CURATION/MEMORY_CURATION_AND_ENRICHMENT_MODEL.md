# FEMC Memory Curation and Enrichment Model

**Version:** 1.0.0
**Status:** Memory Architecture
**Owner:** Memory Office

## Curation

Curation may organize memories by:

- person;
- relationship;
- event;
- date;
- place;
- theme;
- story;
- family tradition.

## Enrichment

AI or system assistance may suggest context, but suggestions must remain distinguishable from family-confirmed information.

## Principle

Curation should make family history easier to understand without rewriting it.

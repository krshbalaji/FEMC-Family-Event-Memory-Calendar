# FEMC Memory Import and Migration Model

**Version:** 1.0.0
**Status:** Memory Architecture
**Owner:** Memory Office

## Import

Imported memories should preserve, where available:

- original source;
- original timestamps;
- contributors;
- captions/stories;
- relationships;
- provenance;
- original media.

## Migration

Migration must preserve semantic context, not only files.

Uncertain mappings should be flagged rather than silently fabricated.

## Principle

When family history enters FEMC from elsewhere, its origin should remain part of its identity.

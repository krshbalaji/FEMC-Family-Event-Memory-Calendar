# FEMC Media Search and Discovery Model

**Version:** 1.0.0
**Status:** Media Intelligence
**Owner:** Media Office

## Discovery Dimensions

Authorized discovery may use:

- people;
- events;
- places;
- dates;
- captions;
- stories;
- media type;
- visual/audio-derived metadata;
- family themes.

## Rules

Search indexes are derived representations and must respect current media visibility.

Discovery should optimize meaningful retrieval rather than engagement.

## Principle

FEMC should help a family find the right artifact, not simply the most recently viewed artifact.

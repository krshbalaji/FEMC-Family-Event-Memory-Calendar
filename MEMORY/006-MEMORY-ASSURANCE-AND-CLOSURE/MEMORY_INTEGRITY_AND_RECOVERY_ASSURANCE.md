# FEMC Memory Integrity and Recovery Assurance

**Version:** 1.0.0
**Status:** Memory Assurance
**Owner:** Memory Office

## Verify

Memory assurance should consider:

- source integrity;
- metadata integrity;
- relationships;
- provenance;
- media accessibility;
- derived representations;
- recovery behavior.

## Recovery

After recovery or migration, important memories should be reconciled for semantic integrity.

## Principle

A recovered memory that has lost its family context is only partially recovered.

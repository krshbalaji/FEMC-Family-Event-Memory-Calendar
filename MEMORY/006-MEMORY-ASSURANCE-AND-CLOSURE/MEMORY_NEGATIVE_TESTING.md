# FEMC Memory Negative Testing

**Version:** 1.0.0
**Status:** Memory Assurance
**Owner:** Memory Office

## Test Deliberately

Attempt to expose:

- private memories;
- deleted memories;
- incorrect relationships;
- stale search results;
- incorrect AI summaries;
- fabricated context;
- broken media references;
- duplicate memories;
- migrated memories with lost provenance.

## Principle

Memory trust is tested by what the system refuses to invent, expose, or forget—not only by what it successfully displays.

# FEMC Media Expanded Negative Testing

**Version:** 1.0.0
**Status:** Media Assurance
**Owner:** Media Office

## Deliberate Tests

Test:

- interrupted upload;
- partial processing;
- corrupted source;
- broken derivative;
- incorrect content-type;
- duplicate asset;
- lost metadata;
- unauthorized share;
- expired share still accessible;
- AI transformation without provenance;
- storage-provider outage;
- recovery with missing renditions.

## Principle

Media assurance must test both content integrity and the relationships that make content meaningful.

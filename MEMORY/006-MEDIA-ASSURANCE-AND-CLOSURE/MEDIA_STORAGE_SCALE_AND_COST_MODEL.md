# FEMC Media Storage Scale and Cost Model

**Version:** 1.0.0
**Status:** Media Assurance
**Owner:** Media Office

## Scale

Media may grow through:

- family count;
- asset count;
- resolution;
- video duration;
- derivative count;
- AI representations;
- backups;
- exports.

## Priorities

Protect:

1. original/preserved assets;
2. integrity;
3. authorized access;
4. recovery;
5. useful derived representations.

## Principle

Storage optimization must not silently trade away irreplaceable family history.

# FEMC Memory Quality and Trust Model

**Version:** 1.0.0
**Status:** Memory Governance
**Owner:** Memory Office

## Quality Dimensions

- authenticity;
- completeness;
- context;
- provenance;
- clarity;
- temporal accuracy;
- relationship accuracy;
- source confidence;
- preservation integrity.

## Rules

Do not manufacture missing family context merely to make a memory appear complete.

Conflicting accounts should remain distinguishable until appropriately resolved.

## Principle

A partial but honest memory is more trustworthy than a complete-looking memory built on invented certainty.

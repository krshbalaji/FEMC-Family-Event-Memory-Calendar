# FEMC Memory Visibility and Family Context

**Version:** 1.0.0
**Status:** Memory Governance
**Owner:** Memory Office

## Visibility

Memory visibility may depend on:

- family context;
- contributor;
- intended audience;
- event context;
- time;
- authorization;
- privacy choice.

## Rules

A family connection does not automatically create universal memory access.

Resurfacing, search, AI, and exports must respect the effective visibility boundary.

## Principle

Shared family history can contain private chapters; FEMC must preserve that distinction.

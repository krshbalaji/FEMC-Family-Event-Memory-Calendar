# FEMC Memory Context and Provenance Model

**Version:** 1.0.0
**Status:** Memory Governance
**Owner:** Memory Office

## Context

A memory may connect to:

- people;
- relationships;
- event;
- date/time;
- place;
- media;
- story;
- tradition;
- source;
- contributor.

## Provenance

Distinguish:

```text
FAMILY RECORDED
      ↓
SYSTEM DERIVED
      ↓
AI INTERPRETED
      ↓
PRESENTED
```

## Rule

Derived context must not silently become historical fact.

## Principle

Future discovery is trustworthy when the family can distinguish what was remembered from what the system inferred.

# FEMC Memory Intelligence Boundaries

**Version:** 1.0.0
**Status:** Memory Intelligence
**Owner:** Memory Office

## AI May Assist With

- organization;
- retrieval;
- summarization;
- contextual linking;
- timeline construction;
- question answering;
- discovery;
- authorized storytelling.

## AI Must Not Silently

- alter canonical memories;
- invent family facts;
- convert guesses into facts;
- expose restricted memories;
- erase provenance;
- create false certainty.

## Principle

Memory intelligence amplifies family understanding; it does not become the family's historian of record without traceable authority.

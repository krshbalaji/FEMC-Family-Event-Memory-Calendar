# FEMC Memory Discovery and Resurfacing Governance

**Version:** 1.0.0
**Status:** Memory Intelligence
**Owner:** Memory Office

## Discovery

Memory may be discovered through:

- people;
- relationships;
- time;
- events;
- places;
- stories;
- themes;
- family milestones;
- authorized natural-language queries.

## Resurfacing

Resurfacing should consider:

- relevance;
- timing;
- privacy;
- emotional appropriateness;
- repetition;
- user control.

## Principle

FEMC should help a family rediscover meaningful history without turning memory into an engagement algorithm.

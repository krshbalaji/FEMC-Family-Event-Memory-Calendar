# FEMC AI Memory and Context Model

**Version:** 1.0.0
**Status:** AI Domain
**Owner:** AI Office

## Context Layers

```text
CURRENT USER CONTEXT
 ↓
AUTHORIZED FAMILY CONTEXT
 ↓
RELEVANT MEMORY / EVENT CONTEXT
 ↓
TEMPORAL CONTEXT
 ↓
AI TASK
```

## Rules

AI context must be:

- authorized;
- purpose-limited;
- relevant;
- traceable where material;
- minimized where possible.

AI should not retrieve the entire family history merely because it technically can.

## Principle

The best AI context is the smallest authorized context that is sufficient for the task.

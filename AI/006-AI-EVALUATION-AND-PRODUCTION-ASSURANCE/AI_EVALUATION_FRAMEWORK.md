# FEMC AI Evaluation Framework

**Version:** 1.0.0
**Status:** AI Assurance
**Owner:** AI Office

## Evaluation Dimensions

- correctness;
- grounding;
- family-context relevance;
- authorization adherence;
- privacy;
- safety;
- consistency;
- uncertainty;
- tool-use behavior;
- latency;
- cost;
- user correction.

## Evaluation Sets

Use representative and adversarial scenarios, including family-context edge cases and authorization boundaries.

## Principle

AI evaluation must measure trustworthiness for FEMC tasks, not only generic model benchmark performance.

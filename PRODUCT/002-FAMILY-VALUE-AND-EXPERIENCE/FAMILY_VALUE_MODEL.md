# FEMC Family Value Model

**Version:** 1.0.0
**Status:** Product Architecture
**Owner:** Product Office

## Core Value

FEMC creates value by helping families:

- remember;
- connect;
- celebrate;
- communicate;
- discover;
- preserve;
- understand;
- pass family history forward.

## Value Chain

```text
PEOPLE
 ↓
RELATIONSHIPS
 ↓
EVENTS
 ↓
MEMORIES
 ↓
MEDIA
 ↓
CONTEXT
 ↓
INTELLIGENCE
 ↓
FAMILY CONNECTION
 ↓
LEGACY
```

## Principle

The value of FEMC is not the calendar entry. The value is the connected family context that grows around it.

# FEMC Family Memory Product Model

**Version:** 1.0.0
**Status:** Product Architecture
**Owner:** Product Office

## Purpose

Define family memory as a first-class product capability rather than an attachment to events.

## Memory Dimensions

- people;
- relationships;
- events;
- dates;
- places;
- stories;
- photographs;
- videos;
- documents;
- conversations;
- milestones;
- family traditions.

## Experience

A family memory should be discoverable through time, people, relationships, events, and meaningful context.

## Principle

FEMC should help families remember meaning, not merely store files.

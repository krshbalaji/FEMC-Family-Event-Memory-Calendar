# FEMC Product Discovery Framework

**Version:** 1.0.0
**Status:** Product Strategy
**Owner:** Product Office

## Discovery Flow

```text
OBSERVE FAMILY NEED
 ↓
DEFINE PROBLEM
 ↓
UNDERSTAND CONTEXT
 ↓
GENERATE OPTIONS
 ↓
TEST ASSUMPTIONS
 ↓
SELECT
 ↓
BUILD EVIDENCE
```

## Rules

Do not start with a technology and search for a family problem afterward.

Discovery should include trust, privacy, accessibility, operational, and long-term considerations.

## Principle

The family problem is the starting point; the feature is only one possible answer.

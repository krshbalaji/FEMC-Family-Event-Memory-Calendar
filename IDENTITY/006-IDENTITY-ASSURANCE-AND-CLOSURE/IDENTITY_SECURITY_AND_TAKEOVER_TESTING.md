# FEMC Identity Security and Takeover Testing

**Version:** 1.0.0
**Status:** Identity Assurance
**Owner:** Identity Office

## Negative Tests

Test attempts to:

- impersonate another participant;
- abuse account recovery;
- reuse expired sessions;
- bypass identity verification;
- exploit duplicate identities;
- link an unauthorized external identity;
- inherit access after membership changes.

## Principle

Identity assurance is proven against hostile and mistaken behavior, not only successful login.

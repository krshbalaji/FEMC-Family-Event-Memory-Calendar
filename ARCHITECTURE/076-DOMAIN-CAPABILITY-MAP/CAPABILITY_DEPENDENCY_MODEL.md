# FEMC Capability Dependency Model

**Version:** 1.0.0
**Status:** Architecture
**Owner:** Architecture Office

## Dependency Direction

```text
Canonical Family Domain
        ↓
Core Capabilities
        ↓
Derived Intelligence
        ↓
Presentation / External Integrations
```

## Core Capabilities

People and relationships provide family context.

Events and time provide temporal context.

Memories and media preserve experience.

Communication and celebrations activate family participation.

Legacy provides long-term continuity.

## Derived Capabilities

Search, recommendations, analytics, AI summaries, and classifications consume governed information.

They should not become canonical owners.

## Dependency Rule

Optional capabilities must not become mandatory prerequisites for basic access to canonical family history.

## Principle

Dependencies should express real domain relationships, not organizational convenience.

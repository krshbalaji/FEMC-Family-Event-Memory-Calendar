# FEMC Family Event Architecture

**Version:** 1.0.0
**Status:** Architecture
**Owner:** Architecture Office

## Event Concept

A family event represents meaningful change or occurrence in family life.

Events may connect:

- people;
- relationships;
- places;
- memories;
- media;
- stories;
- future plans.

## Architectural Distinction

```text
DOMAIN EVENT
    ≠
TECHNICAL MESSAGE
    ≠
CALENDAR DISPLAY
```

A domain event expresses family-domain meaning. Technical messages are implementation mechanisms.

## Principle

Event architecture should connect time and family meaning without coupling every capability to one calendar implementation.

# FEMC Platform Capability Architecture

**Version:** 1.0.0
**Status:** Architecture
**Owner:** Architecture Office

## Platform Capabilities

Potential shared capabilities include:

- identity;
- authorization;
- notifications;
- search;
- media;
- AI;
- audit;
- configuration;
- observability;
- workflow;
- storage;
- integration.

## Rule

A platform capability exists to provide reusable infrastructure to domains; it must not absorb domain meaning merely because multiple domains use it.

## Principle

Shared infrastructure should reduce duplication without creating a shared-domain monolith.

# FEMC Policy and Configuration Boundary

**Version:** 1.0.0
**Status:** Architecture
**Owner:** Architecture Office

## Distinction

**Constitution** defines enduring principles.

**Policy** defines governed rules.

**Configuration** defines operational values.

**Family Data** defines canonical family reality.

These must not be silently conflated.

## Example

A notification frequency setting is configuration.

A rule restricting access to private memories is policy.

The principle that privacy must never be compromised is constitutional.

A family's actual memory is canonical domain data.

## Principle

Clear separation prevents operational settings from rewriting product meaning.

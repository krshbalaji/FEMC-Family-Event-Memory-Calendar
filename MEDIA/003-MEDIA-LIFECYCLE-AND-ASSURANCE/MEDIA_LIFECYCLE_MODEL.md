# FEMC Media Lifecycle Model

**Version:** 1.0.0
**Status:** Media Architecture
**Owner:** Media Office

## Lifecycle

```text
CAPTURE / IMPORT
 ↓
VALIDATE
 ↓
STORE / PRESERVE
 ↓
DERIVE
 ↓
USE / SHARE
 ↓
ARCHIVE
 ↓
DELETE / PRESERVE
```

## Requirements

Lifecycle decisions should account for:

- originals;
- derivatives;
- metadata;
- indexes;
- backups;
- exports;
- provider copies;
- AI-generated representations.

## Principle

Media lifecycle governance follows the asset across every copy and representation that materially affects family access or meaning.

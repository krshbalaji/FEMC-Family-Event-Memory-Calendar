# FEMC Media Negative Testing

**Version:** 1.0.0
**Status:** Media Assurance
**Owner:** Media Office

## Deliberate Tests

Test:

- corrupted media;
- missing originals;
- broken derivatives;
- incorrect metadata;
- unauthorized sharing;
- stale provider copies;
- duplicate assets;
- failed uploads;
- interrupted processing;
- AI transformation losing provenance;
- deleted assets resurfacing.

## Principle

Media trust requires testing both whether an asset survives and whether its meaning and authorization survive with it.

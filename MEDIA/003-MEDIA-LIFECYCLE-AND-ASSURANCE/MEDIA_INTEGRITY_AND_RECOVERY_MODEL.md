# FEMC Media Integrity and Recovery Model

**Version:** 1.0.0
**Status:** Media Assurance
**Owner:** Media Office

## Integrity

Where appropriate, verify:

- asset identity;
- content integrity;
- metadata;
- provenance;
- derivative relationships;
- storage completeness.

## Recovery

Recovery should distinguish:

- original/master restoration;
- derivative reconstruction;
- metadata restoration;
- index rebuilding;
- external-provider rehydration.

## Principle

A recovered file is not a fully recovered family asset if its provenance, context, or relationships are lost.

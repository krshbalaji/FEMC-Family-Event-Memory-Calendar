# FEMC Media Closure and Continuous Evolution

**Version:** 1.0.0
**Status:** Media Foundation Closure
**Owner:** Media Office

## Coverage

Media foundations now address:

- media authority;
- asset semantics;
- family media model;
- originals and derivatives;
- renditions;
- metadata;
- provenance;
- lifecycle;
- integrity;
- recovery;
- negative testing.

## Closure Rule

The Media foundation is sufficiently defined when new media capabilities can be evaluated against established rules for asset identity, provenance, preservation, visibility, transformation, recovery, and future compatibility.

## Principle

Media technology will change; FEMC's responsibility to preserve meaningful family artifacts should not.

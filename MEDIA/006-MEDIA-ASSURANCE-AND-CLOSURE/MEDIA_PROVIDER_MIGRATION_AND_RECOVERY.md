# FEMC Media Provider Migration and Recovery

**Version:** 1.0.0
**Status:** Media Assurance
**Owner:** Media Office

## Migration

Provider migration should preserve:

- asset identity;
- original content;
- metadata;
- provenance;
- relationships;
- visibility;
- derivative lineage.

## Recovery

Derived renditions should be rebuildable where practical.

Provider-specific identifiers should not be required to understand the family asset.

## Principle

A storage provider can change; the family's media history must remain coherent.

# FEMC Media Metadata Provenance and Context

**Version:** 1.0.0
**Status:** Media Governance
**Owner:** Media Office

## Metadata

Relevant metadata may include:

- capture time;
- location;
- creator;
- source;
- device;
- people;
- event;
- story;
- technical format;
- processing history.

## Rules

Imported or inferred metadata must remain distinguishable from family-confirmed metadata where material.

Technical metadata must not be treated as family truth without appropriate validation.

## Principle

Metadata can preserve the context that turns an anonymous file into a family memory artifact.

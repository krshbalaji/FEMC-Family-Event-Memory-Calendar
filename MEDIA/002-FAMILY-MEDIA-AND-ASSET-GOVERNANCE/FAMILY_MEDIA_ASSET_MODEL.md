# FEMC Family Media Asset Model

**Version:** 1.0.0
**Status:** Media Architecture
**Owner:** Media Office

## Asset Model

A material media asset may contain:

- asset identity;
- original representation;
- metadata;
- provenance;
- creator/contributor;
- capture context;
- people;
- event;
- place;
- memory;
- visibility;
- integrity information;
- derivative relationships.

## Media Types

Examples include:

- photographs;
- videos;
- audio;
- documents;
- scanned family artifacts;
- future media formats.

## Principle

The asset model must remain extensible without forcing every media type into identical technical assumptions.

# FEMC Calendar Scale and Performance Model

**Version:** 1.0.0
**Status:** Calendar Assurance
**Owner:** Calendar Office

## Scale Dimensions

Calendar load may grow through:

- family size;
- event history;
- recurring events;
- multiple calendars;
- external providers;
- complex projections;
- reminders.

## Priorities

Protect:

1. canonical Event integrity;
2. responsive upcoming-time experience;
3. correct authorization;
4. reliable synchronization;
5. historical continuity.

## Principle

Calendar performance must not be achieved by weakening temporal or access correctness.

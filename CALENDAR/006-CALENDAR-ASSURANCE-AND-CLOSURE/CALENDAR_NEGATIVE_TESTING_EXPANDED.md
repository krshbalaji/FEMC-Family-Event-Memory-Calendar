# FEMC Calendar Expanded Negative Testing

**Version:** 1.0.0
**Status:** Calendar Assurance
**Owner:** Calendar Office

## Deliberate Tests

Test:

- daylight-saving transitions;
- time-zone migration;
- recurring-event exceptions;
- duplicate reminders;
- stale shared views;
- concurrent edits;
- external-provider conflicts;
- deleted-event resurrection;
- unauthorized calendar projection;
- AI-generated false scheduling assumptions.

## Principle

Calendar assurance must test real-world time behavior as well as ordinary data failures.

# FEMC Calendar Negative Testing

**Version:** 1.0.0
**Status:** Calendar Assurance
**Owner:** Calendar Office

## Deliberate Tests

Test:

- time-zone shifts;
- daylight-saving transitions;
- duplicate projections;
- stale event state;
- cancelled event reminders;
- recurrence exceptions;
- external sync conflicts;
- unauthorized shared views;
- deleted events resurfacing;
- calendar provider outages.

## Principle

Calendar trust is demonstrated when time remains coherent under change, conflict, and failure.

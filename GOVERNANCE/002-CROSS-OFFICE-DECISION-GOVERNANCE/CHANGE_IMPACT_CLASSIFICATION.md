# FEMC Change Impact Classification

**Version:** 1.0.0
**Status:** Governance
**Owner:** Governance Office

## Class A — Local

No material effect outside the owning responsibility.

## Class B — Cross-Component

Affects multiple implementation areas but remains within approved architecture.

## Class C — Architectural

Changes boundaries, data ownership, trust, integration topology, or material resilience characteristics.

## Class D — Product

Changes family-facing meaning, workflows, or core product behavior.

## Class E — Constitutional

Changes a non-negotiable principle or enduring product commitment.

## Rule

The higher the class, the stronger the required review and authority.

## Principle

Classify changes before deciding who needs to approve them.

# FEMC Institutional Memory Model

**Version:** 1.0.0
**Status:** Governance
**Owner:** Governance Office

## Preserve

- Constitution;
- major product decisions;
- architectural decisions;
- engineering constraints;
- operational lessons;
- risk history;
- important exceptions;
- governance decisions;
- ecosystem decisions.

## Requirements

Important knowledge should remain:

- discoverable;
- contextualized;
- versioned;
- attributable;
- understandable to future teams.

## Principle

FEMC's institutional memory should explain not only what was built, but why it was built that way.

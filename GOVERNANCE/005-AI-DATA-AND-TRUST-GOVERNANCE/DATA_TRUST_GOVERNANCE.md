# FEMC Data Trust Governance

**Version:** 1.0.0
**Status:** Governance
**Owner:** Governance Office

## Trust Classes

```text
CANONICAL FAMILY TRUTH
DERIVED FAMILY CONTEXT
OPERATIONAL DATA
AI-DERIVED OUTPUT
EXTERNAL DATA
```

## Rules

Each class must have clear:

- ownership;
- authorization;
- provenance;
- retention;
- modification authority;
- portability expectations.

Derived information must not silently override canonical information.

## Principle

FEMC must always know which information is family truth and which information is interpretation.

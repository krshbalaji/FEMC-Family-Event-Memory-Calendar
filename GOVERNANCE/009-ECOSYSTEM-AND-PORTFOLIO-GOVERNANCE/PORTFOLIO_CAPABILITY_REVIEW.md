# FEMC Portfolio Capability Review

**Version:** 1.0.0
**Status:** Governance
**Owner:** Governance Office

## Review Questions

For each major capability:

- Does it strengthen the family mission?
- Does it duplicate existing capability?
- Does it introduce unnecessary complexity?
- Does it create material privacy or security risk?
- Is it portable?
- Is it maintainable for ten years?
- Does it justify its operational cost?
- Can it be retired safely?

## Decision Outcomes

**INVEST** — strengthen and expand.

**MAINTAIN** — retain with controlled evolution.

**SIMPLIFY** — reduce complexity.

**REPLACE** — migrate to a better approach.

**RETIRE** — remove without harming canonical family history.

## Principle

A bigger FEMC is not automatically a better FEMC.

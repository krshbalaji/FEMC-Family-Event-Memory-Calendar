# FEMC Place to Event and Memory Linkage

**Version:** 1.0.0
**Status:** Places Architecture
**Owner:** Places Office

## Relationships

```text
PLACE
 ├── EVENT
 ├── MEMORY
 ├── PEOPLE
 ├── RELATIONSHIP
 └── JOURNEY
```

Each connected domain retains its own authority.

A place can provide context for an event or memory without becoming the owner of that domain's meaning.

## Principle

Places connect family context; they do not absorb neighboring domains.

# FEMC Places Expanded Negative Testing

**Version:** 1.0.0
**Status:** Places Assurance
**Owner:** Places Office

## Deliberate Tests

Test:

- geocoder disagreement;
- stale provider information;
- exact-location leakage;
- historical place shown as current;
- incorrect coordinate conversion;
- map-provider outage;
- route hallucination;
- unauthorized journey reconstruction;
- approximate place becoming exact;
- deleted location resurfacing.

## Principle

Geographic systems require testing for both semantic error and privacy exposure.

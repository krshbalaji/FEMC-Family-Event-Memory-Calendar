# FEMC Places Responsibility and Decision Boundaries

**Version:** 1.0.0
**Status:** Places Foundation
**Owner:** Places Office

## Places Decisions

The Places Office governs:

- place representation;
- geographic context;
- place identity;
- place relationships;
- temporal place context;
- provenance;
- place correction;
- place lifecycle.

## Coordination

Places coordinates with:

- Identity for people;
- Events for event locations;
- Memory for memory context;
- Privacy for location sensitivity;
- Data for canonical representation;
- Communication for location-aware messaging.

## Principle

Places provides geographic meaning to family capabilities without becoming a tracking system by default.

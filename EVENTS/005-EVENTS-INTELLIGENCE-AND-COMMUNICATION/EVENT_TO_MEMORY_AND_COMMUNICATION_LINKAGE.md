# FEMC Event to Memory and Communication Linkage

**Version:** 1.0.0
**Status:** Events Architecture
**Owner:** Events Office

## Relationships

```text
EVENT
 ├── MEMORY
 ├── PEOPLE
 ├── RELATIONSHIPS
 └── COMMUNICATION
```

An event may trigger or contextualize a memory or communication, but those domains retain their own ownership.

## Rules

A communication triggered by an event must respect the event's current state and recipient authorization.

A memory associated with an event must preserve provenance rather than inheriting assumptions automatically.

## Principle

Events connect family capabilities without becoming the owner of their meanings.

# FEMC Events Expanded Negative Testing

**Version:** 1.0.0
**Status:** Events Assurance
**Owner:** Events Office

## Deliberate Tests

Test:

- daylight-saving transitions;
- time-zone changes;
- recurring-event exceptions;
- duplicate reminders;
- stale calendar projections;
- concurrent event edits;
- imported calendar conflicts;
- provider synchronization failure;
- AI-created false event candidates;
- authorization changes after event creation.

## Principle

Temporal systems require failure testing across both data state and real-world time behavior.

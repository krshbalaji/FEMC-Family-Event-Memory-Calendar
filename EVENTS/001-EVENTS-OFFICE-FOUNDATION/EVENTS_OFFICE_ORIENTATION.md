# FEMC Events Office Orientation

**Version:** 1.0.0
**Status:** Events Foundation
**Owner:** Events Office

## Mission

Provide FEMC with a durable understanding of family events as meaningful occurrences in time, rather than treating the calendar as merely a scheduling interface.

## Events Owns

- event semantics;
- temporal context;
- event lifecycle;
- recurrence;
- event relationships;
- event status;
- event quality and assurance.

## Events Does Not Own

The Events Office does not redefine:

- constitutional principles;
- family identity;
- memory meaning;
- communication policy;
- privacy;
- security;
- data storage;
- engineering implementation.

## Principle

A calendar entry is a representation of an event. The family event itself is the domain meaning.

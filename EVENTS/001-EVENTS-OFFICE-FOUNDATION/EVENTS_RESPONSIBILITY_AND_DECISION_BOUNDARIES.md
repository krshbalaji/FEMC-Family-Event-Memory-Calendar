# FEMC Events Responsibility and Decision Boundaries

**Version:** 1.0.0
**Status:** Events Foundation
**Owner:** Events Office

## Events Decisions

The Events Office governs:

- event identity;
- temporal semantics;
- recurrence;
- participants;
- event relationships;
- event state;
- event lifecycle;
- event interpretation boundaries.

## Coordination

Events coordinates with:

- Identity for participants;
- Memory for historical context;
- Communication for reminders;
- Data for canonical representation;
- Privacy for visibility;
- Product for family experience.

## Principle

Events owns what an occurrence means in family time; it does not own every capability that uses that occurrence.

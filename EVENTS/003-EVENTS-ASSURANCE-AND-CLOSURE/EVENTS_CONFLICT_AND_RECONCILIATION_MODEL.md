# FEMC Events Conflict and Reconciliation Model

**Version:** 1.0.0
**Status:** Events Assurance
**Owner:** Events Office

## Conflicts

Possible conflicts include:

- different dates;
- different times;
- different participants;
- duplicate events;
- cancelled versus completed status;
- conflicting imported calendars.

## Rules

Conflicting evidence should remain traceable.

Do not silently select the latest technical record as the historical truth.

## Principle

Event reconciliation is a meaning problem first and a data problem second.

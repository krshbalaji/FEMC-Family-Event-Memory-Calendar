# FEMC Search Index Freshness and Rebuild Assurance

**Version:** 1.0.0
**Status:** Search Assurance
**Owner:** Search Office

## Verify

Monitor:

- indexing lag;
- failed indexing;
- stale permissions;
- stale deletions;
- schema drift;
- incomplete projections;
- rebuild consistency.

## Recovery

Indexes should be rebuildable from canonical sources where practical.

## Principle

Search convenience may temporarily degrade; canonical family knowledge must remain intact.

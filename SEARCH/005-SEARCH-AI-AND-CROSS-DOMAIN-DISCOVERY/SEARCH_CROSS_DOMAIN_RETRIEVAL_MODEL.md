# FEMC Search Cross-Domain Retrieval Model

**Version:** 1.0.0
**Status:** Search Architecture
**Owner:** Search Office

## Retrieval Graph

```text
PEOPLE
  ↕
EVENTS ↔ PLACES
  ↕       ↕
MEMORY ↔ MEDIA
      ↓
   SEARCH
```

Search may connect authorized information across domains while preserving each domain's canonical authority.

## Rule

Cross-domain retrieval must not broaden visibility merely because records are related.

## Principle

Connection increases usefulness; authorization still determines what may be discovered.

# FEMC Search Semantic Query Model

**Version:** 1.0.0
**Status:** Search Architecture
**Owner:** Search Office

## Purpose

Enable family members to search using meaning, relationships, time, place, and natural language rather than requiring exact database terminology.

## Query Interpretation

```text
FAMILY LANGUAGE
      ↓
QUERY UNDERSTANDING
      ↓
SEARCH INTENT
      ↓
AUTHORIZED RETRIEVAL
      ↓
RESULTS
```

## Rules

Interpretation must not change authorization boundaries.

Ambiguous queries should remain ambiguous or request clarification rather than inventing family facts.

## Principle

FEMC should understand how families ask, without pretending certainty about what they meant.

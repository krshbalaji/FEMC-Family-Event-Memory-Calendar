# FEMC Search Explanation and Ambiguity Model

**Version:** 1.0.0
**Status:** Search UX Architecture
**Owner:** Search Office

## Ambiguity

Search should recognize:

- multiple possible people;
- multiple places;
- uncertain dates;
- conflicting records;
- incomplete family context.

## Behavior

Prefer:

1. transparent clarification;
2. bounded results;
3. explicit uncertainty.

Avoid silently selecting a potentially wrong family interpretation.

## Principle

A useful search system knows when it does not know what the family member meant.

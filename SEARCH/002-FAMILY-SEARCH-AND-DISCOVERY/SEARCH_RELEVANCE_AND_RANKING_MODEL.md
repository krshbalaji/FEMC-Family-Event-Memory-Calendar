# FEMC Search Relevance and Ranking Model

**Version:** 1.0.0
**Status:** Search Architecture
**Owner:** Search Office

## Relevance

Ranking may consider:

- query meaning;
- exactness;
- relationship;
- time;
- place;
- event relevance;
- memory relevance;
- user-authorized context.

## Rules

Authorization is a hard boundary, not a ranking signal.

Engagement must not silently become the objective.

## Principle

Relevant does not mean popular; relevant means useful for the family's authorized intent.

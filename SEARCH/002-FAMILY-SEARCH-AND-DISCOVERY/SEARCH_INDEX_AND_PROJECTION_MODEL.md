# FEMC Search Index and Projection Model

**Version:** 1.0.0
**Status:** Search Architecture
**Owner:** Search Office

## Model

```text
CANONICAL SOURCES
      ↓
INDEX / PROJECTION
      ↓
QUERY
      ↓
RANKED RESULTS
      ↓
CANONICAL SOURCE
```

## Rules

Indexes may be rebuilt.

Canonical sources remain the authority.

Material index transformations should preserve provenance and access boundaries.

## Principle

Search accelerates access to truth; it does not create truth.

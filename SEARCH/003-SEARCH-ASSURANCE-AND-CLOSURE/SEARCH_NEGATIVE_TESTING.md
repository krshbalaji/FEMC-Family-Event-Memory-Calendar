# FEMC Search Negative Testing

**Version:** 1.0.0
**Status:** Search Assurance
**Owner:** Search Office

## Deliberate Tests

Test:

- unauthorized result leakage;
- stale deleted records;
- stale permissions;
- incorrect ranking;
- duplicate results;
- broken index;
- partial indexing;
- hallucinated AI retrieval;
- cross-family leakage;
- autocomplete disclosure.

## Principle

Search trust is proven by what cannot be found by the wrong person.

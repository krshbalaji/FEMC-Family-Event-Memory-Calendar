# FEMC Search Closure and Continuous Evolution

**Version:** 1.0.0
**Status:** Search Foundation Closure
**Owner:** Search Office

## Coverage

Search foundations now address:

- search authority;
- principles;
- family search;
- indexing;
- projections;
- relevance;
- ranking;
- privacy;
- authorization;
- negative testing;
- resilience;
- recovery.

## Closure Rule

New search capabilities can be evaluated against established rules for authorization, canonical truth, relevance, provenance, privacy, resilience, and family usefulness.

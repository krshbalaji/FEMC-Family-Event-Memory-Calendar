# FEMC Purpose Limitation and Data Minimization

**Version:** 1.0.0
**Status:** Privacy Governance
**Owner:** Privacy Office

## Questions

Before collecting or using information:

1. What family value does this serve?
2. Is the information necessary?
3. Can the same outcome use less information?
4. Who needs access?
5. How long is it needed?
6. Could the use create unexpected harm?

## AI

AI context should be limited to information necessary for the authorized task.

## Principle

The best family-data architecture is not the one that knows everything; it is the one that uses enough information to create meaningful value without unnecessary exposure.

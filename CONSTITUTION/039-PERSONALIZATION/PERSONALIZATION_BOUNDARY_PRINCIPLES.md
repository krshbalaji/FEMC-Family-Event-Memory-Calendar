# FEMC Personalization Boundary Principles

**Version:** 1.0.0  
**Status:** Foundation  
**Owner:** Chief Product Architect

## 1. Necessary vs Optional

Separate information required for core family functionality from information used only for personalization.

## 2. Permission

Personalization must operate within the user's authorized information boundary.

## 3. Purpose

Use information for a defined product purpose.

## 4. No Sensitive Inference by Default

Do not infer sensitive personal characteristics merely to improve recommendations.

## 5. Family-Level Recommendations

A family-level suggestion must not expose private individual information.

## 6. Individual Recommendations

Individualized assistance must remain within that person's authorized context.

## 7. AI Suggestions

AI-generated recommendations should remain suggestions unless explicitly accepted.

## 8. Correction

Users should be able to correct important personalization assumptions.

## 9. Deactivation

Core FEMC functionality should remain useful when optional personalization is reduced or disabled.

## 10. Principle

Personalization should reduce friction without reducing privacy.

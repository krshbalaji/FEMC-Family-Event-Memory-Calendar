# FEMC Information Architecture Constitution

**Version:** 1.0.0  
**Status:** Constitutional Foundation  
**Owner:** Chief Product Architect

## Purpose

Define how information is conceptually organized across FEMC so that the family record remains coherent, understandable, durable, and evolvable.

## 1. Family Context Is the Organizing Principle

Information should be organized around meaningful family context rather than around application screens.

The primary contextual dimensions are:

- People
- Relationships
- Time
- Events
- Memories
- Media
- Places where relevant
- Celebrations
- Legacy

## 2. Canonical Information

Each core concept must have a canonical representation.

Different views may present the information differently, but they must not create competing truths.

## 3. Contextual Connections

Information becomes more useful when meaningful relationships are preserved.

Examples:

- a person connected to a relationship;
- a relationship connected to an event;
- an event connected to a memory;
- a memory connected to media;
- an event connected to a celebration;
- a memory connected to legacy.

## 4. Time Is Multi-Dimensional

FEMC should be able to represent:

- exact dates;
- date ranges;
- recurring dates;
- approximate dates;
- historical dates;
- unknown dates;
- dates known relative to another event.

The information model must not force false precision.

## 5. Provenance

Where practical, important information should retain its origin.

Possible origins include:

- entered by a person;
- imported;
- generated by a system process;
- suggested by AI;
- derived from other information.

Provenance helps protect trust.

## 6. Version and History

Family information can evolve.

The information architecture should support understanding:

- what is current;
- what was previously true;
- what changed;
- when it changed;
- where the information came from.

Historical continuity is more important than merely storing the latest value.

## 7. Media Is Contextual

A media item should not be treated as meaningful only because it exists.

Photos, videos, audio, and future media should be capable of being associated with meaningful family context.

## 8. Search Is a View Across Information

Search should help people discover relationships across the canonical information model.

Search indexes and AI retrieval structures are derived representations, not replacements for canonical data.

## 9. Information Should Survive Interface Change

The information architecture must remain meaningful if FEMC changes:

- web interface;
- mobile interface;
- voice interface;
- AI interface;
- storage technology;
- cloud provider.

## 10. Information Architecture Test

Ask:

> If the current user interface disappeared tomorrow, would the family information still have clear meaning?

If not, the information architecture is too dependent on presentation.

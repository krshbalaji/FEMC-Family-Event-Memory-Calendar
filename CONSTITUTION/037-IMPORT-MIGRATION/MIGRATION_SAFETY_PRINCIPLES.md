# FEMC Migration Safety Principles

**Version:** 1.0.0  
**Status:** Foundation  
**Owner:** Chief Product Architect

## 1. Inventory

Understand the source before transforming it.

## 2. Map

Map source concepts to canonical FEMC concepts.

## 3. Validate

Identify missing, conflicting, ambiguous, and unsupported information.

## 4. Preserve Originals

Where appropriate, retain original values or provenance so transformations remain understandable.

## 5. Test Relationships

Verify that connected information remains connected after migration.

## 6. Test Historical Meaning

Verify dates, events, memories, and relationship history.

## 7. Verify Permissions

Migration must not accidentally broaden visibility.

## 8. Reconcile

Differences between source and destination should be explainable.

## 9. Recover

A failed migration must have an appropriate recovery path.

## 10. Principle

Never trade irreversible family-history loss for migration convenience.

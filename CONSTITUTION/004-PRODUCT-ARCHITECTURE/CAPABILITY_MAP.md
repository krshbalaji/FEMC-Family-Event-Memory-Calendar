## Capability Rule

A capability is not automatically a domain.

Capabilities may use multiple domain concepts and should reuse canonical data rather than creating parallel meanings.

## Future Capability Test

A proposed capability should answer:

1. What family problem does it solve?
2. Which canonical domain concepts does it use?
3. What new meaning, if any, does it introduce?
4. How does it improve family connection or memory?
5. What privacy implications exist?
6. Can it evolve without corrupting historical data?

# FEMC Change Classification Principles

**Version:** 1.0.0  
**Status:** Foundation  
**Owner:** Chief Product Architect

## Conceptual Classes

### Low Impact
Presentation or operational changes with minimal family impact.

### Moderate Impact
Changes affecting user journeys, derived systems, or non-critical behavior.

### High Impact
Changes affecting:

- canonical data;
- permissions;
- security boundaries;
- privacy;
- migrations;
- core family journeys;
- major AI behavior.

## 1. Classification Drives Review

Higher-impact changes require stronger validation and governance.

## 2. Unknown Impact

When impact is unclear, treat the change conservatively until understood.

## 3. Emergency Changes

Emergency action may be necessary to protect families, but retrospective documentation remains required.

## 4. Principle

The level of governance should match the potential consequence.

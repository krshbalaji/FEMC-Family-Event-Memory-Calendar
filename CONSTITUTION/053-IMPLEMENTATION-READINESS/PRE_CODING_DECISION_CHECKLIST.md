# FEMC Pre-Coding Decision Checklist

**Version:** 1.0.0  
**Status:** Implementation Gate  
**Owner:** Chief Product Architect

Before production coding of a material capability, verify:

- [ ] Product purpose is defined.
- [ ] Owning office is identified.
- [ ] Domain concepts are clear.
- [ ] Canonical vs derived information is clear.
- [ ] Privacy boundary is defined.
- [ ] Access model is defined.
- [ ] Security implications are reviewed.
- [ ] AI involvement is explicitly bounded where applicable.
- [ ] Data provenance is considered.
- [ ] Failure behavior is considered.
- [ ] Recovery implications are considered.
- [ ] Portability implications are considered.
- [ ] Quality expectations are defined.
- [ ] Operational ownership is defined.
- [ ] Dependencies are documented.
- [ ] Constitutional conflicts are resolved.

## Gate Principle

If a material uncertainty affects family trust, data integrity, or architectural meaning, resolve or explicitly govern it before coding.

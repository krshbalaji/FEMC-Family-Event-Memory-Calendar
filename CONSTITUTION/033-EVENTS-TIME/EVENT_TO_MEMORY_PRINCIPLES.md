# FEMC Event-to-Memory Principles

**Version:** 1.0.0  
**Status:** Foundation  
**Owner:** Chief Product Architect

## Lifecycle

```text
EVENT
  ↓
EXPERIENCE
  ↓
MEMORY
  ↓
MEDIA / STORY
  ↓
DISCOVERY
  ↓
LEGACY
```

## 1. Event Is the Context

An event can provide the temporal and relational context for a memory.

## 2. Memory Is Not Mandatory

Not every event produces a stored memory.

## 3. Multiple Memories

One event may have many memories from different people.

## 4. Multiple Events

A memory may relate meaningfully to more than one event where appropriate.

## 5. Personal Perspective

Different family members may remember the same event differently.

FEMC should not automatically force one interpretation to replace another.

## 6. AI

AI may help connect memories to events, but uncertain connections should remain suggestions until appropriately confirmed.

## 7. Privacy

An event's visibility does not automatically grant access to every memory associated with it.

## 8. Principle

Events organize family time; memories preserve family meaning.

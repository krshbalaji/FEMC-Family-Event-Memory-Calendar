# FEMC Communication Preferences and User Control

**Version:** 1.0.0
**Status:** Communication Governance
**Owner:** Communication Office

## Controls

Families should be able to control, where applicable:

- channels;
- categories;
- frequency;
- quiet periods;
- optional communications;
- automated assistance;
- selected family contexts.

## Rules

Essential communications should remain distinguishable from optional communications.

Preference changes should have clear and predictable effects.

## Principle

Communication control is meaningful when families can shape how FEMC reaches them without losing important information they legitimately need.

# FEMC Communication Negative Testing

**Version:** 1.0.0
**Status:** Communication Assurance
**Owner:** Communication Office

## Deliberate Failure Tests

Attempt to trigger:

- wrong recipient;
- revoked recipient;
- private content leakage;
- duplicate delivery;
- stale notification;
- provider outage;
- AI hallucinated message content;
- preference bypass;
- quiet-period bypass;
- partial multi-channel delivery.

## Principle

A trustworthy communication system is defined as much by what it refuses to send as by what it successfully delivers.

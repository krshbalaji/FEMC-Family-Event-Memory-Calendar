# FEMC Communication Principles

**Version:** 1.0.0
**Status:** Communication Foundation
**Owner:** Communication Office

## Principles

1. Purpose before notification.
2. Relevance before frequency.
3. Family context before generic messaging.
4. User control before automation.
5. Clarity before cleverness.
6. Respect before engagement.
7. Privacy before convenience.
8. Reliability before channel expansion.
9. Human tone before machine tone.
10. Accessibility across supported communication modes.
11. Failure must be visible and recoverable.
12. Communication should strengthen family connection, not manufacture dependency.

## Principle

The best FEMC message is one the family actually needed, understood, and trusted.

# FEMC Security Incident Response Framework

**Version:** 1.0.0
**Status:** Security Operations
**Owner:** Security Office

## Response Stages

1. Detect
2. Validate
3. Classify
4. Contain
5. Investigate
6. Eradicate
7. Recover
8. Verify
9. Learn

## Evidence

Preserve appropriate evidence without unnecessarily exposing family information.

## Communication

Incident communication must distinguish confirmed facts, working hypotheses, and unresolved scope.

## Principle

Fast response is valuable; false certainty is dangerous.

# FEMC Security Operating Model

**Version:** 1.0.0
**Status:** Security Foundation
**Owner:** Security Office

## Security Lifecycle

```text
UNDERSTAND
 ↓
PREVENT
 ↓
DETECT
 ↓
RESPOND
 ↓
RECOVER
 ↓
LEARN
```

## Security Scope

Security applies across:

- family experiences;
- APIs;
- canonical data;
- media;
- search;
- AI;
- integrations;
- infrastructure;
- operations;
- support.

## Principle

Security is a continuous property of the ecosystem, not a gate applied immediately before production.

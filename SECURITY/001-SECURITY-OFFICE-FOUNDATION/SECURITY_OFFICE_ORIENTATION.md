# FEMC Security Office Orientation

**Version:** 1.0.0
**Status:** Security Foundation
**Owner:** Security Office

## Mission

Protect FEMC families, family information, platform integrity, and trusted operations against unauthorized access, misuse, compromise, and security failure.

## Security Owns

- security architecture oversight;
- identity and access security;
- threat management;
- security assurance;
- vulnerability management;
- security incident coordination;
- security evidence.

## Security Does Not Own

Security does not redefine:

- family-domain meaning;
- product vision;
- constitutional principles;
- engineering implementation;
- routine operations.

Material conflicts are escalated to the appropriate authority.

## Principle

Security protects FEMC's trust boundaries without becoming an excuse for unnecessary complexity or surveillance.

# FEMC Data Loss and Tamper Protection

**Version:** 1.0.0
**Status:** Security Architecture
**Owner:** Security Office

## Threats

Consider:

- unauthorized modification;
- accidental deletion;
- corruption;
- malicious deletion;
- compromised credentials;
- compromised dependencies;
- recovery artifact tampering.

## Controls

Use appropriate combinations of:

- integrity validation;
- access controls;
- version/history where required;
- protected backups;
- recovery testing;
- anomaly detection.

## Principle

Protecting family memories means protecting both their confidentiality and their integrity.

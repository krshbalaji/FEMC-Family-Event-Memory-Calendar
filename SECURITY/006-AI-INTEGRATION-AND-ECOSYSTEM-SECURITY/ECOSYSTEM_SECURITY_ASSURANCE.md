# FEMC Ecosystem Security Assurance

**Version:** 1.0.0
**Status:** Security Assurance
**Owner:** Security Office

## Assurance Areas

Review material extensions and providers for:

- identity;
- permissions;
- data access;
- isolation;
- vulnerability posture;
- incident response;
- portability;
- retirement behavior.

## Negative Requirement

An extension must not create an alternate route around FEMC authorization.

## Principle

The larger FEMC becomes, the more important it is that every participant remains inside a governed trust boundary.

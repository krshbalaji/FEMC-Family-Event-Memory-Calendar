# FEMC Security Test Strategy

**Version:** 1.0.0
**Status:** Security Assurance
**Owner:** Security Office

## Test Layers

```text
UNIT / COMPONENT
 ↓
API / CONTRACT
 ↓
INTEGRATION
 ↓
SYSTEM
 ↓
ADVERSARIAL / ABUSE
 ↓
RECOVERY
```

## Priority

Deep testing is required for:

- authentication;
- authorization;
- family isolation;
- sharing;
- revocation;
- exports;
- media delivery;
- AI tools;
- external integrations;
- administrative access.

## Principle

Security tests must prove that unauthorized paths remain unauthorized.

# FEMC Security Evidence and Assurance

**Version:** 1.0.0
**Status:** Security Assurance
**Owner:** Security Office

## Evidence Sources

- security tests;
- threat models;
- vulnerability assessments;
- incident history;
- configuration reviews;
- access reviews;
- recovery exercises;
- dependency assessments;
- production security telemetry.

## Rules

Evidence should be attributable, current enough for its purpose, and protected from unauthorized alteration.

Material residual risk must remain visible.

## Principle

Security assurance is confidence supported by evidence, not confidence by reputation.
